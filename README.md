## Compatibility
* `Pacman` 
* `Paru` or `Yay`
* `XBPS`
* `APT`
* `Yum`
* `Nix`
* `Flatpak`

## How to Use

```
git clone https://github.com/Michael-Sebero/Package-Dictionary

cd /home/$USER/Package-Dictionary/tools

pd test
```
